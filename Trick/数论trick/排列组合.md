排列组合

(1) 斯特林数(第一类)（带符号）\(s(n,k)\)：把 n 个元素排成 k 个非空循环排列的方案数（带符号版）。

\(x^{\underline{n}} = \sum_{k=0}^n s(n,k)x^k\)
递推：\(s(n,k) = s(n-1,k-1) - (n-1)s(n-1,k)\)
无符号第一类斯特林数 
\(c(n,k)\)\(c(n,k) = (-1)^{n-k}s(n,k)\)
递推：\(c(n,k) = c(n-1,k-1) + (n-1)c(n-1,k)\)




（2）斯特林数（第二类）：n 个元素分成 k 个非空集合的方案数
\(S(n, k) = \frac{1}{k!} \sum_{i=0}^{k} (-1)^{k-i} \binom{k}{i} i^n\)




（3）n种颜色，涂m问题，其中k种颜色必须要用上
\(\sum_{j=0}^{k} (-1)^j \cdot \binom{k}{j} \cdot (n - j)^m\)

公式解释：

我们总共有 n 种颜色可用。
我们强制要求集合 A（大小为 k）中的颜色必须出现。
我们使用容斥原理，从总情况中排除掉 “集合 A 中有颜色没出现” 的情况。
j 表示集合 A 中没有被使用的颜色数量。
\(\binom{k}{j}\)：从 k 种必选色中选出 j 种不使用。
\((n - j)^m\)：从剩下的 \(n - j\) 种颜色（包含未被排除的必选色和所有可选色）中任选涂 m 面墙。

（4）把 n 个不同元素分到 k 个有标号盒子（盒子非空）
\(k! \cdot S(n,k) = \sum_{i=0}^k (-1)^{k-i}\binom{k}{i}i^n\)

（5）贝尔数（n 个元素的集合划分总数）
\(B_n = \sum_{k=0}^n S(n,k)\)

（6）卡特兰数（经典计数序列）
第 n 个卡特兰数 \(C_n\)：\(C_n = \frac{1}{n+1}\binom{2n}{n}
= \binom{2n}{n} - \binom{2n}{n-1}\)
递推：\(C_0=1,\quad C_{n+1}=\sum_{i=0}^n C_i C_{n-i}\)
常见用途：括号匹配、出栈序列、二叉树计数、凸多边形三角剖分等。

只要题目满足：
1.两种操作数量相等
2.任意时刻操作 A 数量 ≥ 操作 B 数量
直接套 卡特兰数 \(\boldsymbol{C_n = \dfrac{1}{n+1}\dbinom{2n}{n}}\) 即可。

全部都是任意前缀满足：左操作 ≥ 右操作的计数：

合法括号序列计数
栈的出栈序列个数
n 个节点二叉树形态数
凸 \(n+2\) 边形三角剖分方案数
从 \((0,0)\) 到 \((n,n)\) 不穿过对角线的格路数
买票找零问题（5 元、10 元排队）
