## 题目简述

给定一个长度为 \(n\) 的非负整数数组 \(a_1, a_2, \dots, a_n\)，定义子数组和 \(S(i,j) = \sum_{k=i}^j a_k\)。

求所有子数组的权值之和：
\[
\sum_{i=1}^n \sum_{j=i}^n \big( \lfloor \log_2 S(i,j) \rfloor + 1 \big) \times (i + j)
\]

其中特别规定 \(\log_2 0 = 0\)。

- **输入**：多组测试数据，每组第一行 \(n\)，第二行 \(n\) 个整数 \(a_i\)（\(0 \le a_i \le 10^5\)）。  
- **输出**：每组数据的结果。  
- **数据范围**：\(1 \le n \le 10^5\)，\(T\) 组数据。

void solve(){

                ans += i * (sum + cnt * (j + 1));
            }
        }
    }

    return;
}
