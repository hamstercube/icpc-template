# 1.1 三角形公式整理

1.  **半周长**
    $$P = \frac{a+b+c}{2}$$

2.  **面积**
    $$S = \frac{1}{2}aH_a = \frac{1}{2}ab\sin C = \sqrt{P(P-a)(P-b)(P-c)}$$

3.  **中线（$M_a$ 为边 $a$ 对应的中线）**
    $$M_a = \frac{\sqrt{2(b^2+c^2)-a^2}}{2} = \frac{\sqrt{b^2+c^2+2bc\cos A}}{2}$$

4.  **角平分线（$T_a$ 为角 $A$ 对应的角平分线）**
    $$T_a = \frac{\sqrt{bc\left((b+c)^2-a^2\right)}}{b+c} = \frac{2bc\cos\left(\frac{A}{2}\right)}{b+c}$$

5.  **高线（$H_a$ 为边 $a$ 对应的高）**
    $$H_a = b\sin C = c\sin B = \sqrt{b^2-\left(\frac{a^2+b^2-c^2}{2a}\right)^2}$$

6.  **内切圆半径**
    $$
    \begin{align*}
    r &= \frac{S}{P} = \frac{a\sin\left(\frac{B}{2}\right)\sin\left(\frac{C}{2}\right)}{\sin\left(\frac{B+C}{2}\right)} \\
      &= 4R\sin\left(\frac{A}{2}\right)\sin\left(\frac{B}{2}\right)\sin\left(\frac{C}{2}\right) = \sqrt{\frac{(P-a)(P-b)(P-c)}{P}} \\
      &= P\tan\left(\frac{A}{2}\right)\tan\left(\frac{B}{2}\right)\tan\left(\frac{C}{2}\right)
    \end{align*}
    $$

7.  **外接圆半径**
    $$R = \frac{abc}{4S} = \frac{a}{2\sin A} = \frac{b}{2\sin B} = \frac{c}{2\sin C}$$


# 1.2 四边形公式整理

> 说明：
> - $D_1, D_2$ 为对角线长度
> - $M$ 为对角线中点连线长度
> - $A$ 为对角线夹角
> - $a,b,c,d$ 为四边形四条边的长度
> - $P$ 为半周长，$P=\dfrac{a+b+c+d}{2}$

---

1.  **对角线与边长关系（平行四边形定理推广）**
    $$a^2+b^2+c^2+d^2 = D_1^2+D_2^2+4M^2$$

2.  **任意四边形面积公式**
    $$S = \frac{1}{2}D_1D_2\sin A$$

---

以下为**圆内接四边形**专用公式：

3.  **托勒密定理**
    $$ac+bd = D_1D_2$$

4.  **婆罗摩笈多公式（面积）**
    $$S = \sqrt{(P-a)(P-b)(P-c)(P-d)}$$


# 1.3 正 n 边形公式整理

> 说明：
> - $R$ 为外接圆半径，$r$ 为内切圆半径
> - $a$ 为边长，$n$ 为边数
> - $A$ 为中心角，$C$ 为内角
> - $\pi$ 为圆周率

---

1.  **中心角**
    $$A = \frac{2\pi}{n}$$

2.  **内角**
    $$C = \frac{(n-2)\pi}{n}$$

3.  **边长**
    $$a = 2\sqrt{R^2 - r^2} = 2R\sin\frac{A}{2} = 2r\tan\frac{A}{2}$$

4.  **面积**
    $$S = \frac{nar}{2} = nr^2\tan\frac{A}{2} = \frac{nR^2\sin A}{2} = \frac{na^2}{4\tan\frac{A}{2}}$$


# 1.4 圆公式整理

> 说明：
> - $r$ 为圆的半径
> - $A$ 为圆心角（弧度制）
> - $l$ 为弧长，$a$ 为弦长，$h$ 为弓形高
> - $S_1$ 为扇形面积，$S_2$ 为弓形面积

---

1.  **弧长**
    $$l = rA$$

2.  **弦长**
    $$a = 2\sqrt{2hr-h^2} = 2r\sin\frac{A}{2}$$

3.  **弓形高**
    $$h = r - \sqrt{r^2 - \frac{a^2}{4}} = r\left(1-\cos\frac{A}{2}\right) = \frac{a\tan\frac{A}{4}}{2}$$

4.  **扇形面积**
    $$S_1 = \frac{rl}{2} = \frac{r^2A}{2}$$

5.  **弓形面积**
    $$S_2 = \frac{rl - a(r-h)}{2} = \frac{r^2(A - \sin A)}{2}$$


---

# 1.5 棱柱
1.  **体积**：$V = Ah$
    （$A$ 为底面积，$h$ 为高）
2.  **侧面积**：$S = lp$
    （$l$ 为侧棱长，$p$ 为直截面周长）
3.  **全面积**：$T = S + 2A$

---

# 1.6 棱锥
1.  **体积**：$V = \frac{Ah}{3}$
    （$A$ 为底面积，$h$ 为高）

以下为**正棱锥**专用公式：
2.  **侧面积**：$S = \frac{1}{2}lp$
    （$l$ 为斜高，$p$ 为底面周长）
3.  **全面积**：$T = S + A$

---

# 1.7 棱台
1.  **体积**：$V = \frac{(A_1 + A_2 + \sqrt{A_1A_2})h}{3}$
    （$A_1, A_2$ 为上下底面积，$h$ 为高）

以下为**正棱台**专用公式：
2.  **侧面积**：$S = \frac{(p_1 + p_2)l}{2}$
    （$p_1, p_2$ 为上下底面周长，$l$ 为斜高）
3.  **全面积**：$T = S + A_1 + A_2$

---

# 1.8 圆柱
> 说明：$r$ 为底面半径，$h$ 为圆柱的高

1.  **侧面积**
    $$S = 2\pi rh$$

2.  **全面积（表面积）**
    $$T = 2\pi r(h + r)$$

3.  **体积**
    $$V = \pi r^2 h$$

---

# 1.9 圆锥
> 说明：$r$ 为底面半径，$h$ 为圆锥的高，$l$ 为母线长

1.  **母线长**
    $$l = \sqrt{h^2 + r^2}$$

2.  **侧面积**
    $$S = \pi rl$$

3.  **全面积（表面积）**
    $$T = \pi r(l + r)$$

4.  **体积**
    $$V = \frac{1}{3}\pi r^2 h$$

---

# 1.10 圆台
> 说明：$r_1, r_2$ 为上下底面半径，$h$ 为高，$l$ 为母线长

1.  **母线长**
    $$l = \sqrt{h^2 + (r_1 - r_2)^2}$$
2.  **侧面积**
    $$S = \pi(r_1 + r_2)l$$
3.  **全面积**
    $$T = \pi r_1(l + r_1) + \pi r_2(l + r_2)$$
4.  **体积**
    $$V = \frac{\pi(r_1^2 + r_2^2 + r_1r_2)h}{3}$$

---

# 1.11 球
> 说明：$r$ 为球的半径

1.  **表面积（全面积）**
    $$T = 4\pi r^2$$
2.  **体积**
    $$V = \frac{4}{3}\pi r^3$$

---

# 1.12 球台
> 说明：$r$ 为球半径，$r_1, r_2$ 为上下底面半径，$h$ 为球台高

1.  **侧面积**
    $$S = 2\pi rh$$
2.  **全面积**
    $$T = \pi(2rh + r_1^2 + r_2^2)$$
3.  **体积**
    $$V = \frac{\pi h[3(r_1^2 + r_2^2) + h^2]}{6}$$

---

# 1.13 球扇形（球心角体）
> 说明：$r$ 为球半径，$h$ 为球冠高，$r_0$ 为球冠底面半径

1.  **全面积**
    $$T = \pi r(2h + r_0)$$
2.  **体积**
    $$V = \frac{2}{3}\pi r^2 h$$
